## Bar chart: `bar_chart`

- Set true when a claim compares at least two distinct categories or named benchmarks on one numeric measure with a common unit and scale. The claim does not need to state the numbers. “Cristiano Ronaldo scored more goals than Lionel Messi in the UEFA Champions League” compares two players on the same count and calls for this chart. Include the categories, measure and period in the search query.
- Set false for a single figure, a vague comparison without a numeric measure, or a time series trend. Use the specialized chart when applicable, such as a country-stat comparison, population pyramid, price chart, match result, election result, stock heatmap or complete part-to-whole breakdown.
