## Route map: `route_map`

- Set true for a factual claim about a flight route, a trip or transport schedule, distance between named endpoints, or an event with an ordered route, when at least two distinct stops are identified. Include the stops and any route, flight number, event or date in the search query.
- Set false for a single location, a list of unrelated locations, a recommended trip or a claim about the number of flights rather than where they go.
