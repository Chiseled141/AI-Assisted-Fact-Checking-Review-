# ClaimTrace — Candidate Trusted Sources

Draft list of sources to consider for evidence retrieval. Compiled from general knowledge and **not verified** (domains, availability, and current ownership still need checking before use). Each row carries a **trust tag** so the evidence panel can explain why a source counts, instead of showing a bare "trusted" flag.

## Trust tags

Three tags only:

| Tag | Meaning | How ClaimTrace should treat it |
|---|---|---|
| 🟢 Green | Good: official, established or peer-reviewed source with an accountable process | Can be cited as evidence |
| 🟡 Yellow | Mixed: reliable for some things, but non-primary, advocacy, user-generated, entertainment or unverified | Corroboration only; show a caution badge and prefer a green source |
| 🔴 Red | Bad: known for fabricated, deceptive or scam content | Never counts as evidence; show a warning if a claim or URL points to it |

The **Type** column in each table says what kind of source it is (government, wire service, fact-checker, and so on). Tags are suggestions from memory; verify each one before relying on it.

## 11. Safe fallback for sensitive politics and disputed territory (draft)

Some claims have no single agreed answer because the dispute is itself the subject (sovereignty, borders, maps and place names, ongoing conflicts, contested elections). Source tags alone can't settle these: every party's official site is a green primary source for its own position, and they contradict each other.

Proposed behaviour:

| Step | Behaviour |
|---|---|
| Detect | Flag a claim as sensitive when it touches disputed territory or place names, sovereignty or border claims, active conflicts, or contested political legitimacy. Start with a reviewed keyword and entity list, not a model guess. |
| Don't force a verdict | Show a **Contested topic** label instead of Supported / Contradicted. This is separate from Insufficient evidence and from technical failure. |
| Attribute, don't adjudicate | List each party's official position with its source, worded as "X states…", never as fact. Government sites remain green for what they state. |
| Prefer neutral sources | Show intergovernmental and judicial sources first where they exist (UN bodies, icj-cij.org, pca-cpa.org for arbitration cases, UN maps and place-name records), plus wire services and fact-checkers reporting on the dispute. |
| Separate checkable parts | Split out parts that can be verified (a date, a quote, a published figure, whether a document exists) and assess those normally; only the contested core gets the fallback. |
| Human review | Route these claims to review before anything is published as an assessment. Keep the original and later revisions, as with other corrections. |
| Say why | Display a short plain explanation: "This topic is disputed between parties, so ClaimTrace shows the positions and evidence instead of a verdict." |

Open design choices: who maintains the sensitive-topic list, whether the label is shown on the claim card or only in the evidence panel, and how Vietnamese-language place names and phrasing are matched.
